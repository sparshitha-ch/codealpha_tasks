Task 1: Hangman Game

A simple text-based Hangman game developed using Python.

Features

- Random word selection
- Letter-by-letter guessing
- Six incorrect guesses allowed
- Input validation
- Win and lose messages

How to Run

1. Install Python 3.
2. Download "hangman.py".
3. Open a terminal in the file's folder.
4. Run:

python hangman.py

Technology Used

- Python
- Random module
